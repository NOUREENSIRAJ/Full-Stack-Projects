# 🏛️ ArchStudio — Full-Stack Architecture Portfolio

A modern, full-stack architecture studio website featuring an interactive 3D hero section, dynamic project galleries, and a complete admin dashboard for content management.

🔗 **Live Site:** [archstudio-frontend.vercel.app](https://archstudio-frontend.vercel.app)
🔗 **Admin Panel:** [archstudio-frontend.vercel.app/admin/login](https://archstudio-frontend.vercel.app/admin/login)

---

## ✨ Features

- **Interactive 3D Building Model** — Built with Three.js / React Three Fiber
- **Dynamic Video & Image Background Slideshow** — Auto-rotating hero section
- **Project Showcase** — Filterable gallery with image carousels and captions
- **Full Admin Dashboard** — Secure JWT-authenticated CRUD panel to add, edit, and delete projects
- **Contact Form** — Connected to a MongoDB-backed API
- **Smooth Page Transitions** — Framer Motion animations throughout
- **Fully Responsive** — Optimized for desktop and mobile

---

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- Tailwind CSS
- React Three Fiber + Drei (3D)
- Framer Motion (animations)
- React Router DOM
- Axios

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Multer (file uploads)

**Deployment:**
- Frontend & Backend hosted on Vercel
- Database hosted on MongoDB Atlas
