# 🗂️ Full-Stack Projects

A collection of full-stack web applications, ranging from Flask + SQLite apps to a modern MERN stack project with 3D interactivity.

---

## 📌 Projects

### 🏛️ [ArchStudio](./archstudio)
A full-stack architecture studio website featuring an interactive 3D hero section, dynamic project galleries, and a complete admin dashboard.
**Stack:** MERN (MongoDB · Express · React · Node.js) · Three.js · Tailwind CSS

🔗 [Live Site](https://archstudio-frontend.vercel.app) · 🔗 [Admin Panel](https://archstudio-frontend.vercel.app/admin/login)

---

### 🍽️ [Luna & Spice](./Luna%20%26%20Spice)
Restaurant table reservations with per-room capacity, so a room fills up instead of overbooking.
**Stack:** Flask · SQLite · Jinja · CSS

---

### 💇 [Gloss Salon Booking](./gloss-salon-booking)
Salon appointment booking with services and time slots.
**Stack:** Flask · SQLite · Jinja · CSS

---

### 💅 [Gloss Salon Static](./gloss-salon-static)
Static front-end version of the Gloss salon site.
**Stack:** HTML · CSS

---

### 🩺 [WellCrest](./WellCrest)
Doctor appointment booking system.
**Stack:** Flask · SQLite · Jinja · CSS

---

Each project folder has its own README, screenshots, and setup instructions.

## 🚀 Running Locally

### Flask Projects (Luna & Spice, Gloss Salon, WellCrest)

```bash
cd project-folder
pip install -r requirements.txt
python app.py
```

### ArchStudio (MERN Stack)

```bash
cd archstudio/backend
npm install
npm run dev
```

```bash
cd archstudio/frontend
npm install
npm run dev
```
